# Política obligatoria de protección de `main`

La rama `main` debe configurarse en GitHub con:

1. Pull Request obligatorio antes de fusionar.
2. Una aprobación de un integrante distinto del autor.
3. Aprobaciones descartadas cuando existan commits nuevos.
4. Conversaciones resueltas antes de fusionar.
5. Comprobación de CI obligatoria y rama actualizada.
6. Prohibición de `force push` y eliminación de la rama.
7. Aplicación de la regla a administradores cuando la política institucional lo permita.

La configuración efectiva se verifica en `Settings → Rules → Rulesets` y no se sustituye por este documento.
