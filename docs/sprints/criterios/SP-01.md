# SP-01 - Criterios de terminación

Timebox: **4 horas**.

Se considera terminado cuando el equipo documente:

1. Mecanismo viable para autenticar una cuenta institucional `@virtual.upt.pe`.
2. Segunda verificación temporal mediante intranet/SSO, sin almacenar contraseña ni CAPTCHA.
3. Regla para asociar la cuenta autenticada a un único registro universitario.
4. Datos mínimos devueltos al backend Node.js.
5. Riesgos de suplantación, cuenta no asociada y sesión inválida.
6. Adaptador simulado para el prototipo si no existe integración institucional autorizada.

Arquitectura obligatoria: **Flutter -> HTTPS/REST -> Node.js -> MySQL**. Flutter no valida directamente la intranet ni accede a MySQL.
