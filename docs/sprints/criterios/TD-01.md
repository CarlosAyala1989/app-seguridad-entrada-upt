# TD-01 - Criterios de terminación

- Proyecto Flutter organizado por capas y cliente HTTP encapsulado.
- API REST Node.js disponible mediante configuración de entorno.
- Persistencia productiva prevista en MySQL detrás de una interfaz de repositorio; nunca Flutter -> MySQL.
- Soporte para dobles/adaptadores temporales mientras la integración real no esté disponible.
- Estados loading/data/empty/error representables en Flutter.
- Variables sensibles fuera del repositorio y CI en verde.
- README actualizado si cambia el arranque o configuración.
