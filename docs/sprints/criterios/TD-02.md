# TD-02 - Criterios de terminación

- CI ejecuta análisis estático y pruebas de Flutter/Dart.
- CI instala dependencias y ejecuta análisis/pruebas de Node.js.
- La cobertura de dominio se valida con el umbral acordado por la DoD.
- Las integraciones que requieran MySQL utilizan un entorno/base de pruebas, nunca producción.
- Un fallo bloqueante deja el Pull Request no apto para fusionarse.
- Los logs no exponen contraseñas, tokens ni credenciales de base de datos.
